# ZonaRatona 2.0

Tienda online de videojuegos y consolas — DSY1104 Desarrollo Fullstack II, Grupo 3
(Fabian Grez, Lucas Gajardo, Manuel Vargas).

- `frontend/`: aplicación React + Tailwind CSS + json-server (ver [frontend/README.md](frontend/README.md)).
- `index.html`, `login.html`, `productos.html`: versión original en HTML (Evaluación 1).
- `Grupo 3 ERS ZonaRatona v1.0.docx`: Especificación de Requisitos de Software, versión final.

## Ejecutar
```bash
cd frontend
npm install
npm run server   # terminal 1: API en http://localhost:3001
npm run dev      # terminal 2: app en http://localhost:5173
```
